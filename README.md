# Virada 5x2

Consultoria que leva empresas da escala 6x1 para a 5x2 sem perder performance. Projeto em equipe do Empretec, Feira de Santana, novembro de 2026.

| Arquivo | Para quê |
|---|---|
| `index.html` | Aplicativo de celular: coleta os dados da empresa, compara os caminhos (rodízio, fechar um dia, uma hora a menos, 12x36) e monta o plano de transição |
| `plano/plano.pdf` | Plano de negócio pronto para imprimir (A4, 10 páginas) |
| `plano/plano.html` | Fonte editável do PDF |

Os dados de mercado e da lei têm fonte indicada no plano e no aplicativo. Preços, metas, custos e projeções são premissas da equipe.
